What this means

This value is a modeled estimate of ground-shaking intensity (PEIS) based on distance to the modeled West Valley Fault rupture, magnitude 7.2 and a shallow scenario depth. Real shaking varies with local geology, soil amplification, building vulnerability and other factors. The authoritative PHIVOLCS intensity field is shown on the map (toggle “Intensity — PEIS”).

Source: Modeled (derived from a point-source attenuation relation). Official PHIVOLCS deterministic scenario layer rendered as the map overlay. Fault geometry: official PHIVOLCS WMS; centerline used for distance is a simplified trace (see About).

About this Simulation

This interactive tool visualizes a hypothetical Magnitude 7.2 earthquake on the West Valley Fault (WVF) — the ~100 km active fault traversing Bulacan, Rizal, Metro Manila, Cavite and Laguna. It is built for education and disaster-preparedness visualization only.

⚠ Important disclaimer

This is a scenario / hypothetical visualization, NOT an earthquake prediction. DOST-PHIVOLCS has not issued a forecast. Actual earthquake intensity and impacts will differ depending on the precise earthquake source (location, depth, rupture direction), local geology, soil conditions, building vulnerability, and other factors.

Data sources & how it is built

  • Fault trace (map): Rendered live from the official DOST-PHIVOLCS Active Fault map service (ArcGIS WMS / export). This is the authoritative fault geometry and is shown directly.
  • Ground-shaking intensity (map): The official PHIVOLCS “Ground Shaking (Deterministic)” layer — estimates of maximum PEIS intensities for the Valley Fault System M7.2 scenarios — is rendered as the official intensity overlay.
  • Liquefaction (map): Official PHIVOLCS Liquefaction susceptibility layer.
  • Administrative boundary: Metro Manila (NCR) districts boundary, derived from PSA/NAMRIA data (faeldon/philippines-json-maps, MIT).

Click analysis — modeled values

When you click the map, the sidebar shows a modeled estimate of intensity computed from a transparent attenuation relation:

PGA(g) = 100.55·Mw − 2.5 / (R + 20)1.15
R = horizontal distance to fault (km), capped at ≥1 km
× site amplification (×1.3) where soft / liquefiable soils are likely

PGA is then mapped to the PHIVOLCS Earthquake Intensity Scale (PEIS). This is a simplified, deterministic approximation — it prioritizes clarity over the full physics of finite-fault rupture and 3-D site response. Where available, prefer the official PHIVOLCS intensity overlay on the map.

Assumptions

  • Magnitude Mw 7.2 (consistent with PHIVOLCS Valley Fault System maximum-credible scenario).
  • Scenario hypocentral depth ≈ 10 km — a model assumption; the exact depth is not specified by the source and strongly influences near-field shaking.
  • Epicenter placed near the central Metro Manila segment of the WVF for animation purposes (assumption).
  • The fault centerline used only for distance math is a simplified representation of the published PHIVOLCS Valley Fault System trace; the authoritative trace is the PHIVOLCS WMS layer above.

Live data note

The app also attempts a live ArcGIS REST query to the official PHIVOLCS Active Fault service to retrieve the WVF geometry directly. If that request is blocked by the server/CORS in your network, the tool gracefully falls back to the embedded simplified centerline and the official WMS rendering remains the source of truth for the map.
